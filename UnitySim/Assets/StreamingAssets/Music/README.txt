TinyTorque music folder
=======================

Drop audio files here (or into the Music folder next to the game's Saves
folder) to replace the built-in procedural themes. Accepted formats: .ogg,
.wav, .mp3.

Name the file after the slot it fills:

  menu       - main menu / garage / track builder
  generic    - races on non-themed maps (Classic Oval, race circuits, user maps)
  downtown   - Downtown Dash
  toyroom    - Playroom Raceway
  enchanted  - Enchanted Ascent
  haunted    - Graveyard Shift
  results    - race results

Example: put "downtown.mp3" here and Downtown Dash races play your track
instead of the built-in synthwave loop. Files in the save-folder Music
directory win over files here; delete the file to get the procedural theme
back. Songs loop.
